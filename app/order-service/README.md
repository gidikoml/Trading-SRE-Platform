\#  Trading SRE Platform



\##  Project Overview



Trading SRE Platform is an end-to-end DevOps and Site Reliability Engineering (SRE) project that demonstrates how to build, secure, deploy, and monitor a cloud-native application using modern DevOps practices.



The project implements a complete CI/CD and GitOps workflow, from source code management to Kubernetes deployment and production monitoring.



\## 🎯 Project Objectives



\- Build a production-ready Flask application

\- Containerize the application using Docker

\- Automate CI/CD with Jenkins

\- Perform static code analysis using SonarQube

\- Scan container images using Trivy

\- Deploy applications using ArgoCD (GitOps)

\- Monitor infrastructure and applications using Prometheus

\- Visualize metrics using Grafana

\- Expose custom application metrics with Prometheus Client
